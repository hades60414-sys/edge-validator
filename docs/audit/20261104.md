## 2. HIGH

### H-1 震盪/虧損淨值被判成報酬 → 虧損策略 likely-real

位置:`engine/judge_web.py:1695-1717`(權威版)、`app.js:1159-1178`(同判準)

```python
# judge_web.py:1711-1717
if abs_max < 1.5 and any_neg:
    return "returns"
if all_pos and (abs_max > 3 or mono > 0.55):
    return "nav"
if all_pos and mono > 0.6:      # ← 永遠到不了(見 D-1)
    return "nav"
return "returns"
```

淨值全正、最大值 ≤3、上漲步比例 ≤0.55(=任何橫盤或下跌的淨值)→ 落到最後的 `return "returns"`。每個 ≈1.0 的淨值被當成「每期 +100%」報酬:均值 ~1、標準差 ~0.01 → 年化夏普 ~80。`extreme_returns` 警語門檻是 |r|≥10,不觸發;JS 與引擎判準相同,`detect_kind_mismatch` 也不觸發。

重現(`np.random.default_rng(1)`,500 日、日均 −0.05%、日波動 1% 的淨值):

```
kind returns  mono 0.459  max 1.022
verdict likely-real 86.0  sharpe 80.4  warn codes []
同一條淨值正確轉成報酬後: likely-overfit
```

影響:產品核心宣稱「有疑慮就不放行」被正面擊穿——**越爛的淨值越容易被誤判**(下跌 → 上漲步比例低)。既有測試 `test_detect_convert.py::test_nav_near_one_monotoneish` 只測單調淨值。
釘住:`engine/test_audit_units.py::test_audit_h1_choppy_nav_detected_as_nav`、`::test_audit_h1_losing_nav_never_likely_real_via_frontend_path`(strict xfail)。
建議方向(未實作):全正且 `median≈1 ± 0.5`、或 `min > 0.2 且 std/mean < 0.2` 視為淨值;或判為 returns 時若 `mean > 0.5` 直接拒審/強警語;UI 加「淨值/報酬」手動切換。

### M-1 日期正規化丟時區與小數秒(前端路徑繞過 R21 混時區防線)

位置:`engine/judge_web.py:1659`、`:1663-1679`;`app.js:1129-1137`

```python
_DATE_HEAD_RE = _re.compile(r"^(\d{3,4})[-/.](\d{1,2})[-/.](\d{1,2})([T ]\d{1,2}:\d{2}(?::\d{2})?)?")
```
regex 只匹配到秒,其後的 `+08:00` / `Z` / `.250` 被丟棄:
```
'2024-01-02T09:30:00+08:00' -> '2024-01-02 09:30:00'
'2024-01-02T01:30:00Z'      -> '2024-01-02 01:30:00'
'2024-01-02 09:30:00.250'   -> '2024-01-02 09:30:00'
'2024-01-02 09:30:00.750'   -> '2024-01-02 09:30:00'
```
- 公開站一律帶 `raw` → `detect_and_convert` 以正規化後日期**覆蓋** `payload["dates"]`(`judge_web.py:1793`)。`_date_integrity_guard` 的 R21 混時區 UTC 重試(`:933-946`,`test_r21.py` 只測直呼路徑)在前端路徑永遠看不到時區:同一瞬間的 `09:00+08:00` 與 `01:00+00:00` 不再撞成重複,不同瞬間反而可能錯排。
- 500ms bar:直呼 `analyze` → `ok=True`;經前端路徑 → `ok=False, duplicate_dates_reject`(每兩根撞成同一秒,重複率 50%)。

釘住:`test_audit_m1_normalize_keeps_timezone`、`test_audit_m1_subsecond_bars_not_rejected_via_frontend_path`(strict xfail);對照組 `test_audit_m1_direct_path_handles_subsecond_correctly`(綠)。

### M-2 常數報酬:浮點捨入決定判決

位置:`engine/judge_web.py:66-67`(`sharpe = mean/vol if vol > 0`)、`:133-134`(DSR 同型)、`:91-92`
